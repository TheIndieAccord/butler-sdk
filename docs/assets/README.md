# Butler documentation artwork

These editable SVGs use the existing Butler Kept House visual language: linen `#f4f0e8`, paper `#fbf8f2`, ink `#1f1c17`, secondary text `#554e43`, and brass text/lines `#7a5c25`.

| Asset | Purpose |
|---|---|
| [Butler SDK header](butler-sdk-header.svg) | A quiet doorway illustration and product introduction. Decorative artwork, not a replacement logo. |
| [Integration map](integration-map.svg) | The public analytics, player and server paths, with credential boundaries. |
| [Event journey](event-journey.svg) | Intended analytics delivery behavior, including consent and retries. |

The diagrams have text equivalents in [architecture](../architecture.md). Use them together. Labels use system fonts; the files need no network access, image service or build step. The artwork does not introduce Spectral Saga lore or a new Butler mascot.
